# GitHub Repository Size Checker

Install: [user.js](https://github.com/yookibooki/userscripts/raw/main/github-repo-size/user.js) | [License](../LICENSE)

## Description

Shows the actual code size of GitHub repositories, excluding the `.git` directory and other non-source files.

## Installation

1. Install a userscript manager such as [Violentmonkey](https://violentmonkey.github.io).
2. Open the script link above.
3. Create a [personal access token](https://github.com/settings/personal-access-tokens/new) with `repo` scope.
4. Enter the token when prompted.

## Note

A personal access token is required to avoid GitHub API rate limiting. The token is stored in your browser's local storage.
