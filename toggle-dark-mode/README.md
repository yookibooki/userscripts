# Toggle Dark Mode

Install: [user.js](https://github.com/yookibooki/userscripts/raw/main/toggle-dark-mode/user.js) | [License](../LICENSE)

## Description

Toggles dark mode with `Ctrl+Shift+D`.

## Installation

1. Install a userscript manager such as [Violentmonkey](https://violentmonkey.github.io).
2. Open the script link above.
