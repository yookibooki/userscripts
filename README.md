# Userscripts

Browser userscripts for common developer and maintenance tasks.

## Install

1. Install a userscript manager such as [Violentmonkey](https://violentmonkey.github.io), [Tampermonkey](https://www.tampermonkey.net), or [ScriptCat](https://docs.scriptcat.org/en/).
2. Open a script link below.
3. Confirm the install.

## Scripts

- [GitHub Repository Size Checker](https://github.com/yookibooki/userscripts/raw/main/github-repo-size/user.js): Shows the actual code size of GitHub repositories. Use a personal access token to avoid API rate limits.
- [Toggle Dark Mode](https://github.com/yookibooki/userscripts/raw/main/toggle-dark-mode/user.js): Toggles dark mode with `Ctrl+Shift+D`.
- [Google Search Site Switch](https://github.com/yookibooki/userscripts/raw/main/google-search-site-switch/user.js): Adds links to Yandex, Bing, and DuckDuckGo on Google results pages.
- [Google Third-party Apps & Services Bulk Delete](https://github.com/yookibooki/userscripts/raw/main/google-third-party-delete/user.js): Removes connected apps and services from Google Account Connections.
- [Medium to Freedium Redirector](https://github.com/yookibooki/userscripts/raw/main/medium-to-freedium-redirector/user.js): Redirects Medium articles to Freedium.
- [Jina AI Reader Redirect](https://github.com/yookibooki/userscripts/raw/main/jina-ai-reader-redirect/user.js): Opens pages in Jina AI Reader with `Ctrl+Alt+Q`.
- [GitHub Copy README.md](https://github.com/yookibooki/userscripts/raw/main/github-copy-readme/user.js): Copies a repository README to the clipboard with `Ctrl+Shift+X`.
- [VS Code Extension Downloader](https://github.com/yookibooki/userscripts/raw/main/vscode-extension-downloader/user.js): Downloads `.vsix` packages from the VS Code Marketplace.
