# Google Third-party Apps & Services Bulk Delete

Install: [user.js](https://github.com/yookibooki/userscripts/raw/main/google-third-party-delete/user.js) | [License](../LICENSE)

## Description

Removes connected third-party apps and services from Google Account Connections.

## Installation

1. Install a userscript manager such as [Violentmonkey](https://violentmonkey.github.io).
2. Open the script link above.
3. Open [Google Account Connections](https://myaccount.google.com/connections).

## Warning

Review the list before running it. The script removes connected apps and services from your Google account.
