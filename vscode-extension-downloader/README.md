# VS Code Extension Downloader

Install: [user.js](https://github.com/yookibooki/userscripts/raw/main/vscode-extension-downloader/user.js) | [License](../LICENSE)

## Description

Downloads `.vsix` packages from the VS Code Marketplace.

## Installation

1. Install a userscript manager such as [Violentmonkey](https://violentmonkey.github.io).
2. Open the script link above.
