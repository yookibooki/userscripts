# Jina AI Reader Redirect

Install: [user.js](https://github.com/yookibooki/userscripts/raw/main/jina-ai-reader-redirect/user.js) | [License](../LICENSE)

## Description

Press `Ctrl+Alt+Q` to redirect the current page to Jina AI Reader.

## Installation

1. Install a userscript manager such as [Violentmonkey](https://violentmonkey.github.io) or [Tampermonkey](https://www.tampermonkey.net/).
2. Open the script link above.

## Usage

Press `Ctrl+Alt+Q` on any page.

## Note

The script redirects the current URL to `https://r.jina.ai/[current-url]`.
