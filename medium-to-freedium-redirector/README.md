# Medium to Freedium Redirector

Install: [user.js](https://github.com/yookibooki/userscripts/raw/main/medium-to-freedium-redirector/user.js) | [License](../LICENSE)

## Description

Redirects Medium articles to Freedium.

## Installation

1. Install a userscript manager such as [Violentmonkey](https://violentmonkey.github.io) or [Tampermonkey](https://www.tampermonkey.net/).
2. Open the script link above.
