# Google Search Site Switch

Install: [user.js](https://github.com/yookibooki/userscripts/raw/main/google-search-site-switch/user.js) | [License](../LICENSE)

## Description

Adds links to Yandex, Bing, and DuckDuckGo on Google results pages.

## Installation

1. Install a userscript manager such as [Violentmonkey](https://violentmonkey.github.io).
2. Open the script link above.

## Customization

Edit the `engines` array in the script to change the search engines.
